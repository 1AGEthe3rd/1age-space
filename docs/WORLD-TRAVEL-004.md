## Shared virtual flight schedule
The initial PDX–DCA and DCA–PDX virtual routes use a provisional 15-minute UTC-aligned cadence, with boarding opening five minutes before departure and closing 30 seconds before departure. Compressed duration is 80 seconds, matching the existing flight-model phases. These are configurable simulation parameters, not actual airline schedules, and not yet enforced in the existing journey. No real fare, reservation, ticket, identity or payment. Route-specific policy, offsets and duration can be supplied for future cities. Stable flight IDs derive from route ID and UTC departure instant. This is a deterministic client-side schedule model; authoritative server time, operational overrides, persistent bookings and multiplayer synchronization remain future work.

## Airport adapter
